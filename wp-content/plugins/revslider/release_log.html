Version 7.1.8 (31st August 2026)

New Features
  • Seven more Pan and Zoom moves, and each of them changes its mind on the way: Arc Swing, Push and Settle, Pull Back, Glide By, Float, Corner Arc and Tilt Sweep. They are there for a layer, for the slide background and in the Page Effect
  • A template package can now bring whole pages, not only its modules. The page arrives with its blocks in order, its Page Effects already pointing at the modules just installed, and its menus and images
  • A module can now be given a wrapper ID and CSS classes wherever it is placed. The Module Wrapper IDs field in Module Settings finally does something, it had nowhere to be stored before
  • Every page builder now shows the module it holds and offers the same controls: swap it, import one from the library, open the editor, Quick Edit it, and one Module Settings dialog. Elementor, Divi 4 and 5, Avada, WPBakery, BeTheme, block editor
  • Divi 5 gains Block Offsets, Block Depth and a wrapper ID it never had
  • Divi 4 and 5: the Visual Builder now draws the module itself on the canvas instead of a stand in card. A Live Preview Render switch turns it back, and modals, missing modules and unregistered premium ones keep the card
  • Themes and plugins can now list modules, offer the module picker and place a module through a documented API. Until now every integration outside the plugin had to reach into Slider Revolution's internals
  • The slide end can now be dragged on the timeline to set the slide's length, instead of opening Slide Settings for it. It stops where the last animation on the slide ends, and its arrow still leads into the Out animation
  • Story Telling is a new module type. The whole module runs off the page scroll instead of a timer, and Scroll Pace sets how much scrolling a story costs
  • A story now says what it spends its scroll on: the Story Telling panel for the whole track, each slide for its own share, and the timeline ruler switchable from seconds to scroll pixels while the animation is being built
  • Arrows, Bullets, Tabs, Thumbnails and the Scrubber are now picked from a grid of live tiles instead of a dropdown. Each tile is the skin itself, and presets you save get one too, with saving, renaming and deleting on the tile
  • The Progress Bar has presets for the first time: twenty two to pick from, among them coloured and segmented bars, edge bars, rings, a hairline through the middle and a wide tint, and you can save your own
  • The scrubber's track pattern and its idle size can be set at last. The engine drew both all along, but the pattern was nailed to dots and the idle size had no control anywhere
  • Thirty three new navigation skins across all five types: pill, outline and card looks, frosted glass, hard black outlines with an offset shadow, gradient rings, and a set that inverts itself against whatever the slide shows so it reads on any image
Changes
  • The layer Tab Index starts at auto instead of 0, and takes -1 to keep a decorative layer out of the keyboard order. An empty field falls back to auto. 0 left the quick list, it never wrote a tab index in Slider Revolution 6 either
  • Progressive Blur is about four times cheaper to draw and looks the same. Modules already built get it, with nothing to re-save
  • Slider Revolution eases effects back on a device that cannot keep up, and restores them once it can. It ignores the first seconds of loading, so a slow start is not mistaken for a slow device
  • Aligning several layers now moves the anchor with them. A centered layer that is aligned left is anchored left afterwards, so its edge stays put when the layer gets wider
  • Distribute now says so when the selected layers overlap on that axis, instead of pulling them apart into a row. Arrange as Row and Arrange as Column still do that, it is what they are for
  • All eight translations are complete again, with the 154 strings that are new this release, the template package installer among them

  • Fixed the block editor keeping an old copy of the Slider Revolution block's stylesheet until WordPress itself was updated. It is now versioned by the file, so a corrected block card shows up on the next reload
  • Fixed a slider imported from Slider Revolution 6 arriving without any of its add-on settings. They were dropped in silence, so the module opened as if the add-ons had never been on. Sliders imported before this update need importing again
  • Fixed the layer Tab Index appending auto to every number, so picking 5 left 5auto in the field. Fields already saved this way repair themselves when the value is next edited
  • Fixed the layer Tab Index and Rel attributes never reaching the page. Both were saved, but nothing wrote them onto the layer. On a layer that is a link, Rel adds to what the link settings produce, so a new tab link keeps its noopener
  • Fixed the layer Rel attribute only ever growing, so a word deleted from the field stayed, and a link switched from nofollow back to follow stayed nofollow until a full page reload
  • Fixed module search to properly filter by titles and aliases containing dashes
  • Fixed a Filmstrip module keeping its old size when the browser window grew past the module content width. Shrinking the window always worked, so it looked random, and only a reload brought the right size back
  • Fixed the media actions Play, Stop, Toggle, Mute, Unmute and Toggle Mute Media doing nothing when they point at Active Video in Slide and that video is the first layer of the slide. Sliders imported from Slider Revolution 6 hit this most

  • Elementor: fixed the modal settings of a saved widget losing their values when the page was reopened. Session length, delay and scroll offset fell back to their defaults while their switches stayed on, and a custom event name was replaced

  • WPBakery: fixed Module Settings refusing to open a second time on the same element, and no longer losing the module title and the link to the editor when those settings are saved

  • Divi: fixed Module Settings doing nothing on a module placed before this update, and that module's modal, offsets and depth reading back as unset

  • Divi: fixed a page built with Divi 4 printing the module's shortcode as plain text once the site moved to Divi 5. It now renders whether or not it has been converted
  • Elementor: fixed the Slider Revolution panel coming up empty, with no module card and no buttons, on the first page load after the plugin was activated or on any slow one

  • Avada: fixed a module placed without "Override Module Layout" rendering full width to visitors while looking correct to whoever was editing the page
  • Fixed modules vanishing from the page on sites that have Fusion Builder installed alongside another theme or builder. A slider added the way BeTheme, Jupiter, Cornerstone and hand written shortcodes add it rendered as nothing at all
  • Divi: fixed a module set to open as a modal ignoring Pop Up after Time completely, and losing the scroll position it was given. Opening at a scroll offset or inside a container now works as set
  • Fixed the Page FX settings window opening empty on WordPress 7.1, with an alert about the page being cross origin. Chalk Line, Pan and Zoom, Cursor Motion and Scroll Animation can be set up again
  • Fixed the Page FX mark on a small block in the editor covering the picture and hanging out under its bottom edge. It now takes a share of the block it sits on, up to the size it always had
  • Fixed switching an effect on for a gallery or a set of columns looking like nothing happened when a block inside already runs one. Both marks sat in the same corner, so the second one landed under the first
  • Fixed a slide never showing on the front, usually the first one of a module imported from Slider Revolution 6. Modules already built get this, with nothing to re-save
  • Fixed the Gaps switch in the Progress Bar settings turning the whole progress bar off instead of its gaps
  • The scrubber works properly at last. Its handle showed a flat colour, or the last slide's picture, wherever it stood: it now shows the slide it is on, dragging included. Modules already built keep what they saved
  • Fixed the scrubber slide title flipping in flat, and the Thin Bar skin losing the size of its handle arrows and the colour of its track pattern
  • Quick Edit: fixed the poster image standing in as the video's thumbnail too, so picking a poster looked like it changed the video
  • Quick Edit: a module with sound no longer plays it while the module is being edited

Version 7.1.7 (21st August 2026)

New Features
  • Page FX brings Slider Revolution effects to ordinary WordPress blocks, with no module on the page. Switch an effect on from the block toolbar, or place its own block. Settings open in a workbench that browses presets and tunes them
  • Page FX Pan & Zoom: the Ken Burns move on any image or Cover block. Eight moves, from Zoom In to Tilt Drift, with Direction, Corner, Strength, Easing, Duration and Repeat. It starts when the image scrolls into view and pauses when it leaves
  • Page FX Scroll Animation: a block plays a Slider Revolution layer animation as it scrolls in. Twenty-nine animations, including text animations that split a heading into lines, words or characters. It can follow the scroll and wind back
  • Page FX Cursor Motion: a block answers the pointer, leaning toward it, popping, tilting or shying away
  • Twelve slide background filters now run on the core transitions as well as the Transition Pack ones: Grain, Dither, Vignette, Chromatic, Posterize, Halftone, Pixelate, Glitches, Glitch & Noise, Motion Blur, Film and Bokeh
  • Filters have their own tab in the slide background browser, with a live preview and a Strength control, and a filter stays on when a different transition is picked. Each carries its own timing inside the transition, editable per slide
  • Preset browsers instead of dropdowns, across the editor: SunBeam, Hover Morph, Particles, Particle Wave, Custom Shapes and the layer Interaction panel now show a grid of tiles. Each tile renders that preset and plays it on hover
  • The layer Interaction panel is rebuilt. Cursor Icon is a twelve cell grid where hovering a cell shows the real system pointer, and Cursor Motion is a tile browser whose tiles run the effect itself
  • SunBeam Add-On: thirteen presets instead of three, with the controls to match. Tint and Chroma for coloured beams, Threshold and Softness for what the light picks up, Flare for anamorphic streaks, and an Atmosphere section with Dust, Blinds or Canopy
  • Particles Add-On: nine new presets, bringing six shapes into use that shipped with the add-on but no preset ever picked, and answering the cursor. Six older presets renamed to say what they do
  • DepthForge Add-On: many more ways for a 3D object to arrive and leave, with Punch, Blast, Overshoot, Arc, Vortex and Fold, and ten One Shot moves. The tiles show a render of the move itself
  • Applying an animation preset to a 3D object no longer throws away where you put it. Position, rotation and size are kept and the preset animates towards them, with a switch above the Apply button to turn that off
  • Forty-two Custom Shape presets instead of nine, in six families, on tiles that draw the real shape. New among them: Slant, Ring, Arrow, Speech Bubble, Heart, Arch, Notch, Steps, Skyline, Diamond, Hexagon, Sparkle and Burst
  • New Repeat control draws the same shape again, nested inward: concentric rings from an Oval, nested frames from a Rectangle, a contour map from a Blob. Five more Shape Animations run on any shape, and Morph reshapes fourteen shape types
  • The timeline has an end of slide marker that is also the door into the Out animation
  • The Content Flow Container has a Reset button that puts widths, heights and device switches back to what a new module starts with
Changes
  • Every Page FX surface carries the same name and mark, from the block inserter to the sticker on the block itself, and one click from that sticker opens the settings, or the list where a block can run more than one effect
  • A block's Page FX menu marks a running effect with a tint and a tick. The purple edge down the left is gone, since on a block with several effects it turned the list into one striped block instead of four separate answers
  • Post Processing left the Transition Pack Filters tab. It is one selector now, in the same place whichever transition engine a slide uses
  • The slide background transition family Filter (Flash, Grayscale, Sepia) is now called Color, since all three are colour treatments and the word belonged to the filter set
  • The Breakpoints panel explains itself, and its fields accept the whole sensible range of 320 to 3840 instead of five narrow windows that blocked real setups. A 1920 monitor could not be put in the Desktop tier
  • Opening a colour picker is no longer treated as an edit. It used to write the value straight back and run every live colour update on the way in, more than thirty times for a single open
  • The Page FX editor takes its colours, type sizes and radii from the Slider Revolution editor, so it follows the light and dark themes with everything else. The breakpoint being edited is named on a strip above the page
  • The Slider Revolution block in the WordPress editor speaks the same language as the Page FX cards beside it. Select Module and Edit Module wear the effect card buttons, and its fields stand at the editor height rather than the taller WordPress boxes
  • Hover Morph Add-On: the Liquid Mask presets share one palette for the colour behind the cell, ink or bone. That colour only shows where no second image is picked, and layers you have already built are untouched
  • The Custom Shape builder moved from the Style tab to the Layer tab, above Position & Size, where every other layer type keeps its content. Only Fill, Stroke and Stroke Size stay in Style, the way an SVG layer splits
  • Shape Animation only shows the settings that reach the chosen animation. Drift never read Amount, and a full Spin has no arc for it to scale
  • All eight translations completed, 280 strings that had never been translated, the whole Page FX interface among them. Removed revslider-en_US.mo, whose every entry translated English into itself
Bug Fixes
  • Fixed custom responsive breakpoints being ignored on live pages. The front end still read them from where Slider Revolution 6 kept them, so Global Settings only moved the editor stage. The revslider_front_breakpoints filter pins the old widths
  • Fixed the Global Settings never opening again once a breakpoint field had been left empty. Emptying a field now puts its default back, and settings already damaged this way repair themselves the next time the Global Settings are opened
  • Fixed the Content Flow alignment doing nothing at all. Arrows, bullets, tabs, thumbnails, the scrubber and the progress bar sat on the full stage whichever option was picked. Narrower content now gets its navigation on the content edge
  • Fixed the Content Flow width and height fields accepting an empty value, which came back as a module at default size on every slider on the page. Modules already saved without a usable size repair themselves the next time they load
  • Fixed WebGL effects and slide background transitions dropping out on pages with several modules. Preloaded slides claimed a graphics context each and never gave it back. An effect that loses its context now rebuilds the next time its slide is shown
  • WebGL effects no longer leave graphics memory behind each time they are rebuilt. Changing a setting or hovering through a preset browser handed back only part of what the effect had claimed, so a long editing session filled the graphics card
  • Fixed The Cluster and Particle Wave effects disappearing after stepping through the slides of a module and coming back, and The Cluster Magnetic presets showing their source image over the grains. The Cluster now runs on the shared render loop
  • Particle Wave Add-On: fixed the presets that pair visible particles with a strong blur, Poison, Cells and Starry Night, rendering in Safari as flickering square tiles instead of an even depth of field
  • Fixed the Bokeh depth of field blurring by the wrong amount after a module or the browser window was resized
  • Fixed the slide background standing still while its timeline kept running. Every rebuild of the scene added another Pan & Zoom chain on the same layer, and once a spent chain rendered last it pinned the image
  • Fixed the timeline sitting at IDLE while an animation was in fact running, and only the Play button ever moving the playhead. Every real run drives the timeline now, and a seek ends it
  • Fixed the Coverage control of the Pan & Zoom presets doing nothing. Half now finishes the move by the middle of the slide and holds it there. Its labels reach the translations too
  • Fixed a gradient colour field changing its own gradient as soon as it was edited, and a gradient swatch turning into a stock blue gradient the moment its picker was opened. The preview was writing its own ramp and palette onto the stored colour
  • Fixed the colour palette opening behind the Bulk Style Editor, out of sight and out of reach
  • Fixed dropdowns coming up empty when they were left on their default value. Saving strips values that match the default, and the dropdown had nothing left to fall back on. It now shows what a newly created layer would show
  • Fixed settings whose range holds fractional values, such as the Bubble Morph Pulse, showing a slider that could not be dragged, and a slider handle staying on the previous layer value after another layer was selected
  • Fixed the animation preset tabs coming up short the first time they were opened. Presets contributed by an add-on only appeared after switching away and back again
  • Fixed the layer animation Smash (Center) leaving the layer permanently tilted, since its closing keyframe never brought the X rotation home
  • Fixed applying an animation preset to a 3D object resizing it, throwing away the framing a camera or light preset should keep, and stopping every other layer on the slide from animating at all, the 3D world the camera lives on among them
  • Fixed the editor panels throwing when the In scene was left with the Slide Background layer selected, and the back to In tab staying on offer for seconds after it had done its job
  • Fixed a selected Slider Revolution block showing the editor selection frame around its preview only, with the block title row and preview painting over the top and the sides of it
  • Fixed the Shape Animation Speed and Amount fields showing red on a custom shape that had no animation yet, and the Custom Shape panel leaving a block of empty space below the colours on shapes that use none of the lower settings
  • Fixed the Drift shape animation sliding out of its layer on the front end and after any editor reload. The spare copy it draws is kept inside the shape drawing now, rather than by clipping the layer. Shapes already built repair themselves
  • Fixed the Custom Shape browser marking the shape that was applied last instead of the one on the selected layer. The marked tile now follows the layer, and a shape tuned past anything the catalogue describes shows no tile marked at all
  • Removed Morph from the Shape Animations offered for shape types that cannot morph
  • Page FX effects that take over the same image now know about each other, instead of leaving one silently doing nothing on the front end. A Filmstrip takes the pictures over and names what it switched off, and one undo puts it back
  • Fixed a Page FX effect losing its settings panel once another effect had claimed the block, leaving no way to switch it off short of removing the other effect first
  • Fixed the Scroll Animation Page Effect flickering while the page is scrolled, and one set to play every time replaying over and over. Both came from measuring the block by the size its own animation was drawing it at
  • Fixed Page FX showing the last saved page in the WordPress preview instead of the one being previewed
  • Fixed the Page FX settings dialog and colour picker at smaller screen sizes, where the Opacity and Angle boxes stood taller than the hex field beside them and the gradient row wrapped onto two lines
  • Hover Morph Add-On: fixed the Slide Background effect staying on screen after its switch was turned off, where until now it only went away after the editor was reloaded
  • Fixed a fixed font weight being loaded on top of the variable font a theme had already provided, which shut down weight animation across the whole page, so a menu that thickens to bold on hover stayed put
  • Fixed the layer settings tab reading Attibutes, and Layer reading Importar Slider in Brazilian Portuguese
  • Fixed the upload path for add-on images and videos
  • Fixed download_url in the load balancer failing with Invalid destination path for symlinked upload directories

Version 7.1.6 (7th August 2026)

New Features

  • Every slide background transition has an Easing selector

  • Cube, Stage Turn, Toss and Flip take a Direction, Zoom and Tilt
  • Transition Pack: the Cut / Reveal transitions are their own family, with Style, Pattern, Direction and Intensity
  • Ensured the Block Editor detects changes when editing and saving Page Effects settings

Changes

  • Presets holding several effects were split (Switch / Toss / Corners, Noise / Shatter, Cross Fade / Shockwave), and presets that were one effect under different names now share a tile
  • Zoom and Tilt on the 3D transitions are strength steps (Subtle / Medium / Strong) instead of on / off, and Zoom pulls further away. Zoom is shown as unavailable while a Tilt is set
Bug Fixes

  • Fixed grid alignment in the Image Editor
  • Fixed an issue causing newly added keyframes to have undefined aliases
  • Fixed alignment issues with YouTube and Vimeo players
  • The "Remove Frame" button no longer appears for keyframes that cannot be removed
  • Fixed a freeze of up to 40 seconds before the first background transition on Firefox and Windows
  • Fixed the slide background disappearing in the editor after applying a transition without an effect ("None")
  • Fixed the Switch and Distort background transitions failing to run
  • Fixed a black flash on fades through a hold colour, the layer order of Double Parallax, a crash in the filter transitions, and the first transition after a page load being cut short
  • Ken Burns keeps running when navigating back to a slide it already played on
  • Panorama slide backgrounds run through background transitions again
  • The bundled Google Fonts list is loaded once per request instead of up to four times

Version 7.1.5 (27th July 2026)

New Features
  • New Effects part in the animation timeline: add GPU effects to any layer and keyframe them like any other animation, each effect on its own timeline, Vignette, Film Grain, Glitch, Grain, Chromatic Aberration, Halftone, Duotone, Gradient Map, Posterize, Pixelate and Dither (Stylize), Defocus (Blur) and Motion Trail (Motion). Several effects on the same layer share a single WebGL context instead of one each
  • New Performance Observer: it measures the actual framerate, and if it drops below ~46fps for a sustained period the most expensive effects, Blur, Liquid Glass, Background Transitions, Distortion, Filmstrip carousel blur, are automatically simplified step by step instead of dropping frames. The chosen level stays stable for the current slide and starts fresh at full quality on the next one. In our tests a carousel with ~100 blurs went from 16 to over 30fps with minimal visual trade-off and significantly less GPU and CPU load (disable with SR7.perf.off = true)
  • Transition Pack: new Reveal Effect for image and video layers, pick a transition that plays as the layer animates in (Animation Mode timeline, IN scene). It rides the layer's own in-animation duration; Ease is selectable
  • Transition Pack: new Advanced Hover Effect for layers, transition-pack effects play on mouseenter (Interaction panel)
  • Layer Reveal effects from the core catalog: Double Parallax, the Zoom / Rotation / Slide / Cross Fade / Noise / Dream / Pull split tiles, and the 3D cubes (Columns / Rows / Boxes / Rain) can now reveal image and video layers
  • Reveal Effects have a Columns / Rows control to adjust the tile and piece count
  • Distortion: new visual Effect picker, an icon grid replaces the Effect dropdown (Displacement Map / Liquid Fluid / Cursor Zoom / Cursor Pixelate / Cursor Ripple / Sticky Image)
  • Particles Add-On: new Soft Glow / Bokeh rendering, particles can be soft-edged glowing orbs with an optional bright core, plus Additive and Screen blend modes so overlapping lights bloom instead of stacking flat
  • Particles Add-On: new Lifecycle animation, each particle is born small, grows as it fades in, keeps growing as it fades out and respawns elsewhere, with per-particle timing so the field never pulses in sync
  • Particles Add-On: new Depth Parallax hover mode, larger (nearer) particles shift more with the pointer for a layered 3D feel, plus a Spin control that rotates shape particles as they move
  • Particles Add-On: ten new ready-made presets, Bokeh Dream, Bokeh Rise, Bokeh Gold, Bokeh Aurora, Fireflies, Embers, Dust, Fog, Confetti and Falling Petals
  • Carousel: Auto Rotate Direction setting (Right to Left / Left to Right) — reverse autorotate motion and progression order, with matching arrow / bullet / tab navigation

  • Before/After: Handle Position (%) — place the drag button anywhere along the divider
  • Before/After: Follow Drag toggle — optionally keep the handle locked to Handle Position instead of tracking the pointer on the cross-axis
  • Paintbrush Add-On: new Effect mode selector — keep the classic Brush Reveal, or pick Curl Trail, a springy tapering cursor stroke with its own tip / tail colors, width, length, spring, glow and fade
  • The Cluster Add-On: new Resonance behavior — particles settle on a volumetric nodal field (cymatic volume) or a flat Chladni Plate instead of only following gravity, with Morph, Wavelength, Mode N/M/L, Amp, Damping, Drive, Opacity and Strike Decay
  • The Cluster Add-On: Resonance interaction — Mouse Drive (Amplitude / Strike / Local + Strike), Scroll Drive (Wavelength / Morph / Both), Strike button, optional Keep Gravity, and camera Motions (Still, Cinema Orbit, Hero Drift, Slow Tumble, Turntable, Vertigo Tilt)
  • The Cluster Add-On: five new factory presets — Resonance Sphere, Resonance Fold, Chladni Plate, Resonance Tumble and Resonance Vertigo — plus Soft Sphere, Dense Fold, Plate 3×2 and Plate 5×4 pattern shortcuts
  • The Cluster Add-On: new Magnetic behavior — turn a photo into an iron-filings grain cloud that springs back to the image; the cursor acts as a dipole magnet so grains stream along classic field-line arcs, then settle home again (Magnet, Rest, Strength, Threshold, Fill; sample image or layer background)
  • The Cluster Add-On: Magnetic photo fill — cover-fit bake with bilinear color sampling, saturation-safe Normal blending, and denser grains at rest that refine while streaming so the picture stays readable and the filings stay sharp
  • The Cluster Add-On: two Magnetic factory presets — Magnetic Photo and Magnetic Soft

Adds Curved Motion path presets (arc, swoop, whip, drift, hook, lob) and one-click WebGL Looks (Vignette, Film, Grain, Glitch, Noir, Vintage, Duotone, Chromatic, Halftone, Posterize, Pixelate, Dreamy) that render a live preview of the effect right in the grid, with Lifetime and Strength controls
Changes
  • Slide background transitions now render on the GPU: the whole background transition system, fades, motion, the filter transitions, the split and grid effects, and the 3D family (Cube, Stage Turn, Flip, Dynamic Toss), moved from the old canvas engine to WebGL. They stay smooth at full size, and both slides' layers now animate over the changing background
  • The "3D Effects" split transitions now render as real rotating bars instead of a flat approximation
  • Motion Blur now renders natively on the GPU
  • Pan Zoom: independent anchor point, and a rotated layer is covered properly instead of showing its edges
  • WebGL contexts are now released again for out-of-view modules and inactive slides, so a page with many modules uses far fewer of them
  • three.js now ships as its own file and is only downloaded when a module actually needs 3D, a page without 3D effects no longer loads ~780KB of it
  • Distortion: cleaner background edges (mirror texture wrap) removes the border artifacts, so the "BG Scale" zoom setting is no longer needed and was removed, this also ends the size "jump" between slides using different effects
  • Filmstrip slide backgrounds now ride slide transitions, the belt keeps scrolling through the out-animation
Bug Fixes
